# ListaDeTareasGUI
(Java Swing)

## Descripción
Aplicación gráfica en *Java Swing* que permite gestionar una lista de tareas.

### Funcionalidades:
- Añadir nuevas tareas (con botón o tecla Enter).
- Marcar tareas como completadas (con botón o doble clic).
- Eliminar tareas de la lista.
- Estilo visual especial para tareas completadas (gris e itálica).

## Ejecución
1. Abrir el proyecto en *NetBeans*.
2. Ejecutar la clase ListaDeTareasGUI.
